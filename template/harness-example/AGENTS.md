# AI Agent Instructions

General-purpose agent configuration for a software project.

## Goals

- Help the developer write clean, maintainable code.
- Follow the project's existing conventions and style.
- Prefer simple solutions over clever ones.

## Repository layout

- Source code is in `src/`.
- Tests are in `src/test/`.
- Configuration is in the project root.

## Coding conventions

- Follow the language's standard style guide.
- Write tests for new functionality.
- Keep functions short and focused.
- Use descriptive variable and function names.

## What to avoid

- Do not commit secrets or credentials.
- Do not modify CI configuration without asking.
- Do not introduce new dependencies without justification.
- Do not make changes outside the scope of the current task.

## Testing

- Run the test suite before considering a task complete.
- Prefer integration tests over mocking where practical.

## Documentation

- Update the README when behaviour changes.
- Add inline comments only when the why is not obvious.
- Keep commit messages concise and descriptive.
